# Calificador IA

Portal de descarga de **Calificador IA**, la app para docentes que califica tareas con IA, arma materias
(Proyecto Formativo y aula de Moodle) y corrige exámenes de opción múltiple escaneando las hojas.

- Página: https://batucas.github.io/CalificadorIA/
- Descarga: sección *Releases* de este repositorio (archivo `Instalar_Calificador_IA.exe`).
- `version.json` indica la versión vigente: la app lo consulta para avisar de actualizaciones.
